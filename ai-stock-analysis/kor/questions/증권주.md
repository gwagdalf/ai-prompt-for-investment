# 한국 주식 시장 거래대금 추이 차트 사이트

## 1. 한국거래소 (KRX) Data Marketplace - 공식 데이터

- **URL**: https://data.krx.co.kr/
- **특징**: 한국거래소 공식 데이터 제공 사이트로, 가장 정확하고 공신력 있는 데이터
- **주요 기능**:
  - 시장별(코스피/코스닥/코넥스) 일별 거래대금 조회
  - 거래 상하위 50종목 (거래량/거래대금 기준)
  - 한눈에 보는 통계 - 거래대금/시가총액 비율 시각화
  - Excel 파일 다운로드 지원
  - 기간별 통계 (당일, 1개월, 6개월, 1년)
- **주요 메뉴**:
  - 종합정보(일): `[46001]` - 거래량, 거래대금 일별 집계
  - MDCEASY013: 시장 종합정보 조회 화면
  - MDCEASY016: 거래량/거래대금 순위 조회
- **장점**: 공식 데이터, 무상 제공, 엑셀 다운로드
- **단점**: 차트 기능이 제한적, 데이터 다운로드 후 별도 차트 작성 필요

## 2. INDEXerGO (인덱서고) - 통합 분석 차트

- **URL**: https://www.indexergo.com/series/?frq=D&codeId=202
- **특징**: KOSPI 통합 분석 차트, 기술적 분석에 특화
- **주요 기능**:
  - KOSPI 일/월 단위 통합 차트
  - 거래대금, 거래량, 외국인순매수 등 종합 지표
  - 최근 데이터까지 포함 (2026년 4월 기준 최신)
  - 다양한 기간 선택 (일별/월별)
- **장점**: 차트 중심 UI, 다양한 지표 동시 확인 가능
- **단점**: 개별 종목 분석보다는 지수 중심

## 3. 한국은행 금융경제 스냅샷

- **URL**: https://snapshot.bok.or.kr/dashboard/A3
- **특징**: 한국은행 공식 통계, 시각화된 그래프 제공
- **주요 기능**:
  - 국내외 금융경제 현황 시각화
  - 주식시장 거래대금 추이 대시보드
  - 그래프/버블 차트 제공
  - 거시경제 지표와 연동
- **장점**: 거시경제 관점에서 분석 가능, 시각화 품질 우수
- **단점**: 실시간 데이터 아님, 주기별 업데이트

## 4. 다음(Daum) 금융

- **URL**: https://finance.daum.net/domestic/kospi?view=pc
- **특징**: 포털 기반 간편 조회, 대중적인 접근성
- **주요 기능**:
  - 코스피/코스닥 실시간 거래대금
  - 차트 기간 선택: 1일, 1개월, 3개월, 1년, 3년, 10년
  - 거래량 상위 종목
  - 시가총액 별 정렬: https://finance.daum.net/domestic/market_cap
  - 52주 고저가 정보
- **장점**: 직관적인 UI, 장기 차트 가능 (최대 10년)
- **단점**: 세부 지표는 제한적

## 5. 네이버(Naver) 증권

- **URL**: https://finance.naver.com/
- **주요 기능**:
  - 실시간 코스피/코스닥 지수
  - 거래량/거래대금 상위 종목: https://finance.naver.com/sise/sise_quant.naver?sosok=1
  - 개별 종목별 거래대금 차트
  - 공시, 재무제표, 뉴스 통합 조회
- **장점**: 국내 최대 포털 기반, 공시/뉴스/시세 통합
- **단점**: 시장 전체 거래대금 장기 추이 차트는 제한적

## 6. TradingView (트레이딩뷰)

- **URL**: https://kr.tradingview.com/symbols/KRX-KOSPI/
- **특징**: 글로벌 차트 플랫폼, 기술적 분석 도구 풍부
- **주요 기능**:
  - KOSPI/KOSDAQ 인터랙티브 차트
  - 거래량(Volume) 지표 기본 제공
  - 100+ 기술적 지표 및 오실레이터
  - 커스터마이징 가능한 차트
  - 커뮤니티 아이디어 공유
- **장점**: 차트 품질 세계 최고 수준, 다양한 분석 도구
- **단점**: 고급 기능은 유료, 한국어 데이터는 일부 지연

## 7. Investing.com

- **URL**: https://kr.investing.com/indices/kospi-historical-data
- **특징**: 글로벌 금융 포털, 과거 데이터 중심
- **주요 기능**:
  - 코스피 과거 데이터 (일자별 시가/고가/저가/종가/거래량)
  - CSV 다운로드 가능
  - 20년 이상 장기 과거 데이터
  - 경제 캘린더 및 뉴스 연동
- **장점**: 장기 과거 데이터 다운로드 가능, 무료
- **단점**: 광고 많음, 한국어 번역 품질参差不齐

## 8. TradingEconomics

- **URL**: https://ko.tradingeconomics.com/south-korea/stock-market
- **특징**: 국가별 경제/주식 지표 통합
- **주요 기능**:
  - 한국 주식 시장 종합 지표
  - 거래대금, 시가총액 추이
  - 경제 지표와 연동 분석
  - 과거 데이터 차트
- **장점**: 거시경제 지표와 함께 분석
- **단점**: 무료 버전 기능 제한

## 9. 증권플러스 (StockPlus)

- **URL**: https://www.stockplus.com/
- **특징**: 증권사 연동 트레이딩 플랫폼
- **주요 기능**:
  - 실시간 시세 및 거래대금
  - 9개 증권사 거래 연동
  - 전문가 투자 정보
  - 조건 검색 (거래대금 기준 등)
- **장점**: 거래와 분석 통합
- **단점**: 일부 기능은 증권사 계좌 필요

## 10. 알파스퀘어 (AlphaSquare)

- **URL**: https://alphasquare.co.kr/home/stock-summary?code=kospi
- **특징**: AI 기반 주식 분석 플랫폼
- **주요 기능**:
  - 코스피/개별 종목 시세 및 차트
  - 거래량/거래대금 분석
  - AI 기반 점수 및 전망
- **장점**: AI 분석 기능, 모던한 UI
- **단점**: 일부 기능 유료

## 11. SEIBRO (세이브로) - 증권정보포털

- **URL**: https://freesis.kofia.or.kr/
- **특징**: 금융투자협회 공식 증권정보 포털
- **주요 기능**:
  - 시장별 거래대금 통계
  - 금융투자업 통계
  - 공매도 정보
  - 외국인/기관 거래 동향
- **장점**: 공식 통계, 상세한 시장 데이터
- **단점**: 차트 기능은 제한적, UI 다소 복잡
